# Читалка TXT и FB2 (Jetpack Compose)

Учебное Android-приложение на **Kotlin**. Базы данных нет.

## Что реализовано

- Кнопка **«Открыть файл»** и системный выбор файла Android.
- Поддержка **`.txt`** и обычных (не архивированных) **`.fb2`**.
- Индикатор загрузки, чтение в фоновом потоке.
- Вертикальная прокрутка текста; заголовки глав FB2 выделены.
- Ошибки: пустой файл, повреждённый FB2, неверный формат, проблемы чтения.
- Поддержка UTF-8, UTF-16 с BOM и Windows-1251 для TXT.
- Автоматическая светлая/тёмная тема. Разрешений на доступ к памяти нет.

## Как открыть в Android Studio

Проект содержит исходники и файлы Gradle. В этом архиве **нет Gradle Wrapper JAR**, поэтому самый простой способ запуска:

1. Открой Android Studio → **New Project → Empty Activity**.
2. Назови проект `ReaderCompose`, выбери **Kotlin**, `Minimum SDK: API 24`.
3. Заменить содержимое `app/src/main/java/.../MainActivity.kt` и добавить рядом `BookReader.kt` из этого архива. Важно: оба файла должны быть в пакете `com.example.readercompose`, либо поменяй строку `package` в обоих файлах под свой проект.
4. Если пакет нового проекта отличается, не забудь поправить `namespace` и `applicationId` в `app/build.gradle.kts`, либо создай проект сразу с пакетом `com.example.readercompose`.
5. Убедись, что проект использует Jetpack Compose и подключены зависимости `androidx.activity:activity-compose`, Compose Material 3 и `kotlinx-coroutines-android`. Готовый список есть в `app/build.gradle.kts` архива.
6. Нажми **Sync Project with Gradle Files**, затем **Run**.

Если у тебя уже есть Gradle 8.9 и его wrapper, можно использовать файлы сборки архива и открыть саму папку `ReaderCompose`.

**Важно:** выбирай Gradle JDK **17**, чтобы избежать ошибок совместимости Java/Gradle.

## Где какой код

- `MainActivity.kt` — кнопка, окно, загрузка, ошибки и прокрутка текста.
- `BookReader.kt` — чтение TXT и FB2, преобразование в абзацы.
- `AndroidManifest.xml` — запуск приложения.
- `app/build.gradle.kts` — настройки Android и зависимости.
- `examples/` — два файла для проверки.

## Как проверить

1. Передай `examples/example.txt` и `examples/example.fb2` на телефон.
2. Запусти приложение, нажми «Открыть файл» и выбери `.txt`.
3. Повтори с `.fb2` — XML-теги не должны показываться.
4. Попробуй пустой `.txt` — появится ошибка.
5. Попробуй повреждённый `.fb2` — появится ошибка.

Файлы больше 10 МБ отклоняются специально, чтобы учебное приложение не зависало.

## Примечания

- Из FB2 извлекается **текст**. Картинки, стили шрифтов и сноски отдельными окнами не поддерживаются.
- Формат FB2 ZIP (архив `.fb2.zip`) не входит в задание.
- Проект рассчитан на Android API 24 и новее.
